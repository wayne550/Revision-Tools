Completing the Square

A method for rewriting x2 + bx + c as (x + p)2 + q — useful when a quadratic won't factorise nicely, when you need exact surd answers, or when you want the turning point of a parabola without drawing a graph.

1What does "completing the square" mean?

Completing the square means rewriting a quadratic expression x2 + bx + c in the form (x + p)2 + q, where p and q are numbers. It's exactly the same expression written differently — nothing is "solved" yet, it's just repackaged into a shape that's much more useful for certain jobs.

It's worth the extra work because the completed-square form makes two things almost immediate: the turning point (vertex) of the parabola y = x2 + bx + c can be read straight off without drawing a graph, and the equation x2 + bx + c = 0 can be solved even when it won't factorise with whole numbers — giving exact surd answers rather than a rounded decimal from a graph or calculator.

Building on
This page assumes you can expand double brackets like (x + 3)2 = x2 + 6x + 9, and it connects closely to Factorising and Solving Quadratics — completing the square is an alternative method for the same kind of equation, and is especially handy when that method's "two numbers" search fails.

2The basic method: x2 + bx + c

Start from the fact that (x + p)2 = x2 + 2px + p2. Matching this to x2 + bx tells you 2p = b, so p is always half of b. But (x + p)2 on its own expands to include an extra +p2 that the original expression doesn't have — so that amount has to be subtracted straight back off, and then the original constant c is added on as normal.

Worked example
x2 + 6x + 5
Step 1 Halve the coefficient of x to get p: b = 6, so p = 6 ÷ 2 = 3.
Step 2 Write (x + 3)2 and expand it mentally: it equals x2 + 6x + 9 — that's 9 too many compared with the original, which only has +5 at the end.
Step 3 Subtract p2 = 32 = 9 to cancel that extra amount, then add back the original constant c = 5: (x + 3)2 − 9 + 5.
Step 4 Simplify the numbers at the end: −9 + 5 = −4.
Check Expand back out: (x+3)2 − 4 = x2+6x+9−4 = x2+6x+5. ✓ Matches the original.
Result x2 + 6x + 5 = (x + 3)2 − 4.

3When the constant gets awkward

The same method works whatever the numbers look like — sometimes the constant q comes out positive instead of negative. When that happens, it's a hint that the original quadratic has no real roots at all (more on why in section 4), which links to the idea of a discriminant you may meet later — a positive q after completing the square is one early signal of this.

Worked example
x2 − 4x + 9
Step 1 Halve b = −4 to get p = −4 ÷ 2 = −2. Because b is negative, p is negative too — this becomes (x − 2)2, not (x + 2)2.
Step 2 Expand (x − 2)2 = x2 − 4x + 4 — that's 4 too many compared with the original constant.
Step 3 Subtract p2 = (−2)2 = 4, then add back the original constant c = 9: (x − 2)2 − 4 + 9.
Step 4 Simplify: −4 + 9 = 5 — this time the constant is positive.
Check Expand back out: (x−2)2 + 5 = x2−4x+4+5 = x2−4x+9. ✓ Matches.
Result x2 − 4x + 9 = (x − 2)2 + 5. Since a squared term plus a positive number can never be zero or negative, this quadratic has no real roots.

4Reading off the turning point

A squared quantity like (x + p)2 can never be negative — its smallest possible value is 0, and that happens exactly when x = −p (the bit inside the brackets becomes zero). So in (x + p)2 + q, the whole expression is smallest when the squared part is 0, giving a minimum value of exactly q. That means the turning point (the vertex of the parabola) is at (−p, q) — and because the x2 coefficient is positive, it's a minimum point.

Worked example
y = x2 + 6x + 5 = (x + 3)2 − 4
Step 1 The squared term (x + 3)2 is never negative — its smallest possible value is 0.
Step 2 That minimum of 0 happens exactly when x + 3 = 0, i.e. when x = −3.
Step 3 When the squared term is 0, y equals just the constant: y = 0 − 4 = −4. Any other value of x makes the squared term positive, making y bigger than −4 — so this is the lowest point on the curve.
Result The turning point (minimum) is at (−3, −4) — the x-coordinate is the negative of the number inside the bracket, and the y-coordinate is the number left outside it.

5Solving a quadratic equation by completing the square

Once a quadratic is in completed-square form, setting it equal to 0 and rearranging is just like solving a simple equation with an extra square-root step. Isolate the squared bracket, take the square root of both sides — remembering there are two square roots, positive and negative — and then solve the two resulting linear equations.

Worked example
x2 + 6x + 5 = 0
Step 1 Complete the square on the left-hand side, as in section 2: (x + 3)2 − 4 = 0.
Step 2 Isolate the squared bracket by adding 4 to both sides: (x + 3)2 = 4.
Step 3 Take the square root of both sides — don't forget the ±: x + 3 = ±2.
Step 4 Solve each case separately: x + 3 = 2 → x = −1, and x + 3 = −2 → x = −5.
Check (−1)2+6(−1)+5 = 1−6+5 = 0 ✓. (−5)2+6(−5)+5 = 25−30+5 = 0 ✓.
Result x = −1 or x = −5.

This method really earns its keep when the numbers don't come out as neat whole numbers — for example x2 + 2x − 4 = 0 completes to (x + 1)2 − 5 = 0, giving (x+1)2 = 5 and x = −1 ± √5 — an exact surd answer that factorising could never find, since 5 has no pair of integer factors that work.

Common mistakes
  • Sign slip on p. If b is negative, p must be negative too — x2 − 6x + 5 becomes (x − 3)2 + …, not (x + 3)2. Always keep p's sign matching b's sign, since p = b ÷ 2 exactly.
  • Forgetting to subtract p². Writing (x + 3)2 + 5 straight from x2+6x+5 (just copying the constant across) skips the correction entirely — expand it back out to check, and it won't match. The constant term almost always changes.
  • Arithmetic slip combining −p² and c. Especially with negative numbers: for x2 − 4x + 9, it's easy to write −4 − 9 = −13 instead of the correct −4 + 9 = 5. Write out "−p² then + c" as two separate numbers before adding them.
  • Forgetting the ± when solving. (x+3)2 = 4 has two square roots of 4 to consider, x+3 = 2 and x+3 = −2 — missing the negative case loses one of the two solutions.

6When a ≠ 1: factor out a first

If the x2 coefficient isn't 1, completing the square still works, but the constant a needs factoring out of the x2 and x terms first, before the "halve b" step is applied inside the bracket.

Worked example
2x2 + 8x + 3
Step 1 Factor a = 2 out of the first two terms only: 2(x2 + 4x) + 3.
Step 2 Complete the square inside the bracket as before: half of 4 is 2, so x2 + 4x = (x + 2)2 − 4.
Step 3 Substitute back in: 2[(x + 2)2 − 4] + 3. Multiply the −4 by the 2 outside: 2(x + 2)2 − 8 + 3.
Step 4 Simplify: −8 + 3 = −5.
Check Expand: 2(x+2)2−5 = 2(x2+4x+4)−5 = 2x2+8x+8−5 = 2x2+8x+3. ✓ Matches.
Result 2x2 + 8x + 3 = 2(x + 2)2 − 5.

Note the leading 2 stays outside — the turning point is still read off the bracket (here, x = −2), but the minimum value must include the multiplication by a: y = 2(0) − 5 = −5, so the vertex is (−2, −5).

    Find the turning point of y = x2 + 8x + 5 by completing the square.
    Show answer
    Halve b: p = 8 ÷ 2 = 4, so start from (x + 4)2 = x2+8x+16, which is 16 too many. Subtract p2 = 16 and add back c = 5: 16 taken off, 5 added back gives −16+5 = −11. So y = (x + 4)2 − 11. Since (x+4)2 ≥ 0 always, the minimum value of y is −11, occurring when x + 4 = 0, i.e. x = −4. So the turning point is (−4, −11).
  • 4
    Solve x2 + 2x − 4 = 0 by completing the square, giving your answer in exact surd form.
    Show answer
    Halve b: p = 2 ÷ 2 = 1, so (x + 1)2 = x2+2x+1, which is 1 too many. Subtract p2 = 1 and add back c = −4: −1 + (−4) = −5. So x2+2x−4 = (x+1)2 − 5. Setting this to 0: (x+1)2 − 5 = 0 → (x+1)2 = 5 → x + 1 = ±√5 → x = −1 + √5 or x = −1 − √5 (approximately 1.24 or −3.24). This doesn't factorise with whole numbers, which is exactly when completing the square is most useful. Check: (−1+√5)2+2(−1+√5)−4 = (6−2√5)+(−2+2√5)−4 = 0. ✓

9Quick reference

x² + bx + c: halve b to get p, then x²+bx+c = (x + p)² − p² + c. Keep p's sign the same as b's.
Turning point: from (x + p)² + q, the minimum is at (−p, q), since a square is never negative.
Solving = 0: isolate the bracket, square-root both sides (remember ±), then solve each linear equation.
Surd answers: when (x+p)² = k isn't a perfect square, leave the answer as −p ± √k — exact, unlike factorising.
No real roots: if q > 0 in (x+p)²+q, the expression is always positive and the equation has no real solutions.
a ≠ 1: factor a out of the x² and x terms first, complete the square inside the bracket, then multiply the correction back through.
Always check: expand your (x+p)²+q answer back out to confirm it matches the original expression.

See also Factorising and Solving Quadratics for the "two numbers" method — a good first choice when a quadratic factorises neatly, with completing the square as the reliable fallback when it doesn't.
